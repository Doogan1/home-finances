# Bills and income (rules) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the household describe every bill and income stream as a rule that produces dates, change it from a date ("Change from…"), stop it ("Stop on…"), fix a version in place, and see them all on a Bills & income page. This is build step 2 of the bills and forecast design.

**Architecture:** Four new tables (`Rule`, `RuleVersion`, `Allocation`, `OccurrenceOverride`) with the design's database rules as hand-written constraints. Everything that computes is pure and lives in `src/features/rules/` (dates a rule produces, splits, monthly amounts, planning a change, form drafts), so pages, client forms and tests share one implementation and the forecast (step 3) reuses it. A server-only service does the writes inside one transaction per action, locking the rule's row so two edits never interleave. Six small POST routes follow the existing guard pattern. Occurrences are never stored: only per-date edits are, and step 2 only creates their table and shows them read-only.

**Tech Stack:** Next.js 16 App Router (Server Components, Suspense, route handlers), Prisma 7 with `@prisma/adapter-pg`, PostgreSQL 17 (`btree_gist` for the no-overlap rule), zod 4, Vitest (unit and integration), Playwright.

**Spec:** `docs/superpowers/specs/2026-11-14-bills-and-forecast-design.md` (this plan covers its build step 2; read its "Data model", "Rules enforced by the database", "Rules enforced by the server", "Recurrence" and "Screens" sections).

## Global Constraints

- Money is stored as `Decimal(19, 4)` and handled as exact decimal **strings** in application code; arithmetic is done in whole cents with `BigInt` (`src/lib/cents.ts`), never JavaScript floating point.
- Calendar dates are `@db.Date`, which Prisma reads and writes as a `Date` at UTC midnight. Application code passes them around as `"YYYY-MM-DD"` strings (`IsoDate`), which compare correctly as strings.
- No default time zone is assumed. Pages that need "today" ask for the household time zone when it is unset (reuse `TimeZoneForm`).
- Every mutating route starts with `authorizeMutation(request)` before reading params, the body, or the database (enforced by `tests/security-static.test.ts`).
- Every response from the new routes is `cache-control: no-store` (use `jsonNoStore`). Request bodies are strict zod objects.
- The household id comes only from the session; every query filters on it.
- Modules under `src/lib/` and `src/features/` import `"server-only"` unless they are pure and listed in the `deliberatelyUnmarked` set in `tests/security-static.test.ts`.
- Rules are never deleted by the app, only archived. Per-date edits are never deleted by an edit to their rule.
- Run commands inside the app container (`docker compose exec app …`) unless the step says "on the host". After a migration, `docker compose restart app`.
- Read `node_modules/next/dist/docs/` for any Next.js API you are unsure of (this is Next.js 16: `params` and `searchParams` are Promises).
- Commit at each task's commit step on the working branch, staging only that task's files. Never stage `AGENTS.md` or anything under `docs/superpowers/`.

## Decisions this plan makes where the spec is silent

These are binding for the tasks below. Each is small to reverse.

1. **Exactly one `REMAINDER` in every version**, even a version with one allocation (a single-account bill or income is one `REMAINDER`). The spec requires it only for versions with more than one; a lone `PERCENT 50` would leave money unaccounted for.
2. **Rules may use hand-entered accounts only, for now** (error `account_linked`). `Allocation.accountId` is `onDelete: Restrict`, so a rule pointing at a Plaid-linked account would make removing that Plaid connection fail. Step 6 (attach) revisits this together with the Plaid delete behaviour.
3. **"Change from…" and "Stop on…" act on the latest version only.** "Edit this version" can change or clear the latest version's end date, which is how a mistaken "Stop on…" is undone.
4. **`Allocation.position`** (an `Int`) keeps the order the person entered the splits in, for display ("70% Ally Spend · 15% PNC · rest Ally Savings").
5. **`MONTHLY` needs a `dayOfMonth` and no `secondDay`** (database check), in addition to the spec's checks.
6. **Interval limits:** weekly 1–52, monthly 1–24.
7. **The version a list shows** is the one in effect today, else the next one to start, else the latest.
8. **Archiving an account without a household time zone** counts every version that uses it as still in use (there is no "today" to compare with).
9. **`tsconfig.json` targets ES2020**, so BigInt literals (`100n`) type-check. It affects type-checking only.
10. **Not in step 2:** the forecast, Home overview, a navigation bar, and any screen that writes per-date edits (step 5). The rule's page shows existing per-date edits read-only.

```ts
/**
 * Exact money arithmetic in whole cents. Amounts arrive as decimal strings
 * (from parseMoney, or Prisma's Decimal(19, 4) via toFixed()), become BigInt
 * cents, and leave as decimal strings, so nothing passes through floating point.
 */

export type Cents = bigint;

const DECIMAL = /^(-?)(\d+)(?:\.(\d{1,4}))?$/;
const PERCENT = /^(\d+)(?:\.(\d{1,4}))?$/;

export function toCents(amount: string): Cents {
  const match = DECIMAL.exec(amount.trim());
  if (!match) throw new RangeError(`Not a decimal amount: ${amount}`);
  const fraction = (match[3] ?? "").padEnd(4, "0");
  if (fraction.slice(2) !== "00") throw new RangeError(`More than two decimal places: ${amount}`);
  const cents = BigInt(match[2]) * 100n + BigInt(fraction.slice(0, 2));
  return match[1] === "-" ? -cents : cents;
}

export function fromCents(cents: Cents): string {
  const negative = cents < 0n;
  const size = negative ? -cents : cents;
  const fraction = (size % 100n).toString().padStart(2, "0");
  return `${negative ? "-" : ""}${size / 100n}.${fraction}`;
}

/** `percent` (such as "70" or "12.5", up to 4 decimals) of an amount, rounded half up to the cent. */
export function percentOf(cents: Cents, percent: string): Cents {
  const match = PERCENT.exec(percent.trim());
  if (!match || cents < 0n) throw new RangeError(`Cannot take ${percent}% of ${cents}`);
  // The percentage in ten-thousandths of a percent, so 12.5% is 125000.
  const scaled = BigInt(match[1]) * 10000n + BigInt((match[2] ?? "").padEnd(4, "0"));
  // cents × percent / 100 = cents × scaled / 1,000,000; adding half the divisor rounds half up.
  return (cents * scaled + 500000n) / 1000000n;
}
```

```ts
import { z } from "zod";
import { parseIsoDate } from "./calendar-date";
import { parseMoney } from "./money";

/**
 * Fields shared by the routes' strict request schemas. Money leaves as a
 * canonical decimal string, dates as "YYYY-MM-DD". Pure, so forms can use them.
 */

export function moneyField(allowNegative: boolean) {
  return z
    .string()
    .max(32)
    .transform((value, ctx) => {
      const parsed = parseMoney(value, { allowNegative });
      if (parsed === null) {
        ctx.addIssue({ code: "custom", message: "Not an amount" });
        return z.NEVER;
      }
      return parsed;
    });
}

export const isoDateField = z
  .string()
  .max(10)
  .refine((value) => parseIsoDate(value) !== null, "Not a date");

/** Free text that may be left blank: trimmed, and "" becomes null. */
export function optionalText(max: number) {
  return z
    .string()
    .trim()
    .max(max)
    .transform((value) => (value === "" ? null : value));
}
```

```ts
import { addDays, daysBetween, type IsoDate } from "@/lib/calendar-date";

/**
 * The dates a rule produces, computed whenever they are needed (nothing is
 * stored, so nothing needs regenerating). Pure and synchronous: pages, forms
 * and the forecast all compute the same dates from the same code.
 */

export type Recurrence = "ONCE" | "WEEKLY" | "MONTHLY" | "TWICE_MONTHLY";

export type Pattern = {
  recurrence: Recurrence;
  interval: number;
  anchorDate: IsoDate;
  dayOfMonth: number | null;
  secondDay: number | null;
};

export type DatedPattern = Pattern & { effectiveFrom: IsoDate; effectiveTo: IsoDate | null };

export type Occurrence<V> = { date: IsoDate; version: V };

/** Longer than the longest gap a pattern can have (24 months). */
const SEARCH_DAYS = 800;

const pad = (value: number, width = 2) => String(value).padStart(width, "0");
const iso = (year: number, month: number, day: number): IsoDate => `${pad(year, 4)}-${pad(month)}-${pad(day)}`;

/** Months counted from year 0, so consecutive months differ by one. */
const monthIndex = (date: IsoDate) => Number(date.slice(0, 4)) * 12 + Number(date.slice(5, 7)) - 1;
const fromMonthIndex = (index: number) => ({ year: Math.floor(index / 12), month: (index % 12) + 1 });

export function daysInMonth(year: number, month: number): number {
  return new Date(Date.UTC(year, month, 0)).getUTCDate();
}

/** `day` of the month, or the month's last day when the month is shorter. */
export function clampedDay(year: number, month: number, day: number): IsoDate {
  return iso(year, month, Math.min(day, daysInMonth(year, month)));
}

function need(value: number | null, what: string): number {
  if (value === null) throw new RangeError(`This schedule needs ${what}`);
  return value;
}

/** Every date the pattern produces in [from, to], in order. Nothing before the anchor. */
export function patternDates(pattern: Pattern, from: IsoDate, to: IsoDate): IsoDate[] {
  const start = from > pattern.anchorDate ? from : pattern.anchorDate;
  if (start > to) return [];
  const dates: IsoDate[] = [];
  switch (pattern.recurrence) {
    case "ONCE":
      // start is never before the anchor, so the anchor counts only when it is the start.
      if (pattern.anchorDate === start) dates.push(start);
      break;
    case "WEEKLY": {
      const step = 7 * pattern.interval;
      const skip = Math.ceil(daysBetween(pattern.anchorDate, start) / step);
      for (let date = addDays(pattern.anchorDate, skip * step); date <= to; date = addDays(date, step)) dates.push(date);
      break;
    }
    case "MONTHLY": {
      const day = need(pattern.dayOfMonth, "a day of the month");
      const anchor = monthIndex(pattern.anchorDate);
      for (let k = Math.floor((monthIndex(start) - anchor) / pattern.interval); ; k++) {
        const { year, month } = fromMonthIndex(anchor + k * pattern.interval);
        const date = clampedDay(year, month, day);
        if (date > to) break;
        if (date >= start) dates.push(date);
      }
      break;
    }
    case "TWICE_MONTHLY": {
      const days = [need(pattern.dayOfMonth, "a first day"), need(pattern.secondDay, "a second day")];
      for (let index = monthIndex(start); ; index++) {
        const { year, month } = fromMonthIndex(index);
        if (iso(year, month, 1) > to) break;
        for (const day of days) {
          const date = clampedDay(year, month, day);
          if (date >= start && date <= to) dates.push(date);
        }
      }
      break;
    }
  }
  return dates;
}

/** The dates a version produces inside both its own range and [from, to]. */
export function versionDates(version: DatedPattern, from: IsoDate, to: IsoDate): IsoDate[] {
  const low = from > version.effectiveFrom ? from : version.effectiveFrom;
  const high = version.effectiveTo !== null && version.effectiveTo < to ? version.effectiveTo : to;
  return low > high ? [] : patternDates(version, low, high);
}

/** A rule's occurrences across its versions (which never overlap), in date order. */
export function ruleOccurrences<V extends DatedPattern>(versions: readonly V[], from: IsoDate, to: IsoDate): Occurrence<V>[] {
  return versions
    .flatMap((version) => versionDates(version, from, to).map((date) => ({ date, version })))
    .sort((a, b) => a.date.localeCompare(b.date));
}

/** The first `count` occurrences on or after `from`, looking up to five years ahead. */
export function nextOccurrences<V extends DatedPattern>(versions: readonly V[], from: IsoDate, count: number): Occurrence<V>[] {
  return ruleOccurrences(versions, from, addDays(from, 5 * 366)).slice(0, count);
}

/** The first date the pattern produces on or after `date`, or null if there is none. */
export function firstOnOrAfter(pattern: Pattern, date: IsoDate): IsoDate | null {
  return patternDates(pattern, date, addDays(date, SEARCH_DAYS))[0] ?? null;
}
```

```ts
import { percentOf, toCents, type Cents } from "@/lib/cents";

/**
 * How one occurrence's amount is divided across accounts. Percentages are
 * rounded half up to the cent, fixed amounts are taken as given, and the one
 * REMAINDER gets what is left, so the shares always add up to the amount.
 */

export type AllocationMode = "PERCENT" | "FIXED" | "REMAINDER";
export type AllocationLike = { accountId: string; mode: AllocationMode; value: string | null };
export type Share = { accountId: string; cents: Cents };

export class SplitError extends Error {
  constructor(readonly code: "needs_one_remainder" | "over_allocated") {
    super(code);
    this.name = "SplitError";
  }
}

function fixedShare(allocation: AllocationLike, amount: Cents): Cents {
  if (allocation.value === null) throw new RangeError(`A ${allocation.mode} allocation needs a value`);
  return allocation.mode === "PERCENT" ? percentOf(amount, allocation.value) : toCents(allocation.value);
}

export function splitAmount(amount: Cents, allocations: readonly AllocationLike[]): Share[] {
  if (allocations.filter((a) => a.mode === "REMAINDER").length !== 1) throw new SplitError("needs_one_remainder");
  const shares = allocations.map((a) => ({ accountId: a.accountId, cents: a.mode === "REMAINDER" ? 0n : fixedShare(a, amount) }));
  const rest = amount - shares.reduce((sum, share) => sum + share.cents, 0n);
  if (rest < 0n) throw new SplitError("over_allocated");
  return shares.map((share, i) => (allocations[i].mode === "REMAINDER" ? { ...share, cents: rest } : share));
}
```

```ts
import { formatMoney } from "@/features/plaid/format";
import type { IsoDate } from "@/lib/calendar-date";
import { fromCents, toCents, type Cents } from "@/lib/cents";
import type { DatedPattern, Pattern } from "./recurrence";
import type { AllocationLike } from "./splits";

/** How rules read on screen, and which list each belongs in. Pure display logic. */

const WEEKDAYS = ["Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"];

export function formatIsoDate(date: IsoDate): string {
  return new Intl.DateTimeFormat("en-US", { dateStyle: "medium", timeZone: "UTC" }).format(new Date(`${date}T00:00:00Z`));
}

export function ordinal(n: number): string {
  const lastTwo = n % 100;
  if (lastTwo >= 11 && lastTwo <= 13) return `${n}th`;
  const suffix: Record<number, string> = { 1: "st", 2: "nd", 3: "rd" };
  return `${n}${suffix[n % 10] ?? "th"}`;
}

/** 31 is how a schedule says "the last day of the month". */
function dayName(day: number | null): string {
  if (day === null) return "";
  return day === 31 ? "last day" : ordinal(day);
}

export function describeSchedule(pattern: Pattern): string {
  switch (pattern.recurrence) {
    case "ONCE":
      return `Once, ${formatIsoDate(pattern.anchorDate)}`;
    case "WEEKLY": {
      const weekday = WEEKDAYS[new Date(`${pattern.anchorDate}T00:00:00Z`).getUTCDay()];
      return pattern.interval === 1 ? `Every ${weekday}` : `Every ${pattern.interval} weeks, ${weekday}`;
    }
    case "MONTHLY": {
      const day = dayName(pattern.dayOfMonth);
      return pattern.interval === 1 ? `Monthly, ${day}` : `Every ${pattern.interval} months, ${day}`;
    }
    case "TWICE_MONTHLY":
      return `${dayName(pattern.dayOfMonth)} and ${dayName(pattern.secondDay)}`;
  }
}

/** a ÷ b rounded half up, for positive values. */
const divideHalfUp = (a: bigint, b: bigint) => (2n * a + b) / (2n * b);

/** About how much a month: weekly × 52 ÷ 12, every N months ÷ N, twice a month × 2; none for a one-off. */
export function monthlyEquivalent(amount: Cents, pattern: Pick<Pattern, "recurrence" | "interval">): Cents | null {
  const interval = BigInt(pattern.interval);
  switch (pattern.recurrence) {
    case "ONCE":
      return null;
    case "WEEKLY":
      return divideHalfUp(amount * 52n, 12n * interval);
    case "MONTHLY":
      return divideHalfUp(amount, interval);
    case "TWICE_MONTHLY":
      return amount * 2n;
  }
}

export type NamedAllocation = AllocationLike & { accountName: string };

/** "70.0000" → "70", "12.50" → "12.5". */
const plainNumber = (value: string) => (value.includes(".") ? value.replace(/\.?0+$/, "") : value);

function describeShare(allocation: NamedAllocation): string {
  switch (allocation.mode) {
    case "PERCENT":
      return `${plainNumber(allocation.value ?? "")}% ${allocation.accountName}`;
    case "FIXED":
      return `${formatMoney(fromCents(toCents(allocation.value ?? "0")), "USD")} ${allocation.accountName}`;
    case "REMAINDER":
      return `rest ${allocation.accountName}`;
  }
}

export function describeAllocations(allocations: readonly NamedAllocation[]): string {
  if (allocations.length === 1) return allocations[0].accountName;
  const ordered = [...allocations.filter((a) => a.mode !== "REMAINDER"), ...allocations.filter((a) => a.mode === "REMAINDER")];
  return ordered.map(describeShare).join(" · ");
}

const byStart = (a: DatedPattern, b: DatedPattern) => a.effectiveFrom.localeCompare(b.effectiveFrom);

export function latestVersion<V extends DatedPattern>(versions: readonly V[]): V {
  const sorted = [...versions].sort(byStart);
  const latest = sorted[sorted.length - 1];
  if (!latest) throw new RangeError("A rule always has at least one version");
  return latest;
}

/** The version in effect on `date`; else the next one to start; else the latest. */
export function versionFor<V extends DatedPattern>(versions: readonly V[], date: IsoDate): V {
  const sorted = [...versions].sort(byStart);
  return (
    sorted.find((v) => v.effectiveFrom <= date && (v.effectiveTo === null || v.effectiveTo >= date)) ??
    sorted.find((v) => v.effectiveFrom > date) ??
    latestVersion(sorted)
  );
}

export type RuleState = "active" | "ended" | "archived";

export function ruleState(rule: { archivedAt: Date | null; versions: readonly DatedPattern[] }, today: IsoDate): RuleState {
  if (rule.archivedAt) return "archived";
  const { effectiveTo } = latestVersion(rule.versions);
  return effectiveTo !== null && effectiveTo < today ? "ended" : "active";
}

export type RuleGroup = "income" | "checking" | "cards";

/** Bills paid from a card are shown separately: the card payment, not the bill, moves cash. */
export function ruleGroup(kind: "INCOME" | "BILL", accountTypes: readonly string[]): RuleGroup {
  if (kind === "INCOME") return "income";
  return accountTypes.includes("credit") ? "cards" : "checking";
}
```

```ts
import { addDays, type IsoDate } from "@/lib/calendar-date";
import { toCents, type Cents } from "@/lib/cents";
import { clampedDay, firstOnOrAfter, nextOccurrences, type DatedPattern, type Pattern } from "./recurrence";
import { SplitError, splitAmount, type AllocationLike, type Share } from "./splits";
import { latestVersion } from "./summary";

/**
 * The rules about versions that need no database: what a schedule and a split
 * must satisfy, and what "Change from…", "Stop on…" and "Edit this version"
 * would write. Pure, so the service and the forms' previews agree exactly.
 */

export type RuleErrorCode =
  | "rule_not_found"
  | "version_not_found"
  | "rule_archived"
  | "account_not_found"
  | "account_archived"
  | "account_linked"
  | "income_to_credit"
  | "bill_needs_one_account"
  | "needs_one_remainder"
  | "over_allocated"
  | "pays_account_invalid"
  | "anchor_not_on_day"
  | "anchor_before_start"
  | "change_not_after_start"
  | "rule_ended"
  | "no_later_occurrence"
  | "stop_before_version_start"
  | "end_before_start"
  | "only_latest_version_can_end";

export type RuleKind = "INCOME" | "BILL";
export type VersionDraft = Pattern & { amount: string; note: string | null; allocations: AllocationLike[] };
export type StoredVersion = VersionDraft & DatedPattern & { id: string };
export type Planned<T> = { ok: true; value: T } | { ok: false; code: RuleErrorCode };

const refuse = (code: RuleErrorCode): { ok: false; code: RuleErrorCode } => ({ ok: false, code });

export function scheduleProblem(pattern: Pattern, effectiveFrom: IsoDate): RuleErrorCode | null {
  if (pattern.anchorDate < effectiveFrom) return "anchor_before_start";
  if (pattern.recurrence === "MONTHLY" && pattern.dayOfMonth !== null) {
    const year = Number(pattern.anchorDate.slice(0, 4));
    const month = Number(pattern.anchorDate.slice(5, 7));
    if (clampedDay(year, month, pattern.dayOfMonth) !== pattern.anchorDate) return "anchor_not_on_day";
  }
  return null;
}

function splitOrCode(amount: string, allocations: readonly AllocationLike[]): Share[] | RuleErrorCode {
  try {
    return splitAmount(toCents(amount), allocations);
  } catch (error) {
    if (error instanceof SplitError) return error.code;
    throw error;
  }
}

export function allocationProblem(
  kind: RuleKind,
  amount: string,
  allocations: readonly (AllocationLike & { accountType: string })[],
): RuleErrorCode | null {
  if (kind === "BILL" && (allocations.length !== 1 || allocations[0].mode !== "REMAINDER")) return "bill_needs_one_account";
  if (kind === "INCOME" && allocations.some((a) => a.accountType === "credit")) return "income_to_credit";
  const shares = splitOrCode(amount, allocations);
  return typeof shares === "string" ? shares : null;
}

export type ChangeFrom = { from: IsoDate; amount: string; note: string | null; allocations: AllocationLike[]; schedule: Pattern | null };
export type NewVersion = VersionDraft & { effectiveFrom: IsoDate; effectiveTo: IsoDate | null };

const patternOf = (v: Pattern): Pattern => ({
  recurrence: v.recurrence,
  interval: v.interval,
  anchorDate: v.anchorDate,
  dayOfMonth: v.dayOfMonth,
  secondDay: v.secondDay,
});

/**
 * Change from date D: the latest version ends on D − 1 and a copy with the
 * edits starts on D. Unless the schedule itself changes, the copy keeps the
 * old pattern, anchored on its first date on or after D.
 */
export function planChangeFrom(
  versions: readonly StoredVersion[],
  change: ChangeFrom,
): Planned<{ endVersionId: string; endOn: IsoDate; next: NewVersion }> {
  const current = latestVersion(versions);
  if (change.from <= current.effectiveFrom) return refuse("change_not_after_start");
  if (current.effectiveTo !== null && change.from > current.effectiveTo) return refuse("rule_ended");

  let schedule = change.schedule;
  if (schedule === null) {
    const anchorDate = firstOnOrAfter(current, change.from);
    if (anchorDate === null) return refuse("no_later_occurrence");
    schedule = { ...patternOf(current), anchorDate };
  }
  const problem = scheduleProblem(schedule, change.from);
  if (problem) return refuse(problem);

  return {
    ok: true,
    value: {
      endVersionId: current.id,
      endOn: addDays(change.from, -1),
      next: {
        ...patternOf(schedule),
        effectiveFrom: change.from,
        effectiveTo: current.effectiveTo,
        amount: change.amount,
        note: change.note,
        allocations: change.allocations,
      },
    },
  };
}

/** Stop on date D: the latest version's last possible day becomes D. */
export function planStop(versions: readonly StoredVersion[], on: IsoDate): Planned<{ versionId: string; effectiveTo: IsoDate }> {
  const current = latestVersion(versions);
  if (on < current.effectiveFrom) return refuse("stop_before_version_start");
  return { ok: true, value: { versionId: current.id, effectiveTo: on } };
}

export type VersionEdit = VersionDraft & { effectiveTo?: IsoDate | null };

/** Edit this version, in place. Only the latest version's end date may change (that is how a stop is undone). */
export function planEdit(
  versions: readonly StoredVersion[],
  versionId: string,
  edit: VersionEdit,
): Planned<{ effectiveTo: IsoDate | null }> {
  const version = versions.find((v) => v.id === versionId);
  if (!version) return refuse("version_not_found");
  let effectiveTo = version.effectiveTo;
  if (edit.effectiveTo !== undefined && edit.effectiveTo !== version.effectiveTo) {
    if (version.id !== latestVersion(versions).id) return refuse("only_latest_version_can_end");
    effectiveTo = edit.effectiveTo;
  }
  if (effectiveTo !== null && effectiveTo < version.effectiveFrom) return refuse("end_before_start");
  const problem = scheduleProblem(edit, version.effectiveFrom);
  if (problem) return refuse(problem);
  return { ok: true, value: { effectiveTo } };
}

export type ChangePreview = {
  endOn: IsoDate;
  next: { date: IsoDate; amount: string }[];
  perAccount: { accountId: string; change: Cents }[];
};

const shareOf = (shares: readonly Share[], accountId: string) => shares.find((s) => s.accountId === accountId)?.cents ?? 0n;

/** What "Change from…" would do, for the form: the end date, the next dates, and each account's change per occurrence. */
export function previewChange(versions: readonly StoredVersion[], change: ChangeFrom, count = 3): Planned<ChangePreview> {
  const plan = planChangeFrom(versions, change);
  if (!plan.ok) return plan;
  const current = latestVersion(versions);
  const before = splitOrCode(current.amount, current.allocations);
  const after = splitOrCode(change.amount, change.allocations);
  if (typeof before === "string") return refuse(before);
  if (typeof after === "string") return refuse(after);

  const accountIds = [...new Set([...before, ...after].map((s) => s.accountId))];
  const perAccount = accountIds
    .map((accountId) => ({ accountId, change: shareOf(after, accountId) - shareOf(before, accountId) }))
    .filter((p) => p.change !== 0n);
  const next = nextOccurrences([plan.value.next], change.from, count).map((o) => ({ date: o.date, amount: change.amount }));
  return { ok: true, value: { endOn: plan.value.endOn, next, perAccount } };
}
```

```ts
import { parseIsoDate } from "@/lib/calendar-date";
import { parseMoney } from "@/lib/money";
import { toPattern, type ScheduleBody } from "./input";
import type { Pattern, Recurrence } from "./recurrence";
import type { AllocationLike, AllocationMode } from "./splits";

/**
 * What the rule forms hold while someone types, and how that becomes a request
 * body (checked again by the server) or a pattern for a live preview.
 */

export type AccountChoice = { id: string; name: string; type: string };

export type ScheduleDraft = {
  recurrence: Recurrence;
  interval: string;
  anchorDate: string;
  lastDay: boolean;
  dayOfMonth: string;
  secondDay: string;
};

export function emptySchedule(recurrence: Recurrence = "MONTHLY"): ScheduleDraft {
  return { recurrence, interval: "1", anchorDate: "", lastDay: false, dayOfMonth: "1", secondDay: "15" };
}

export function scheduleDraftFrom(pattern: Pattern): ScheduleDraft {
  return {
    recurrence: pattern.recurrence,
    interval: String(pattern.interval),
    anchorDate: pattern.anchorDate,
    lastDay: pattern.recurrence === "MONTHLY" && pattern.dayOfMonth === 31,
    dayOfMonth: String(pattern.dayOfMonth ?? 1),
    secondDay: String(pattern.secondDay ?? 15),
  };
}

const wholeNumber = (text: string): number | null => (/^\d{1,3}$/.test(text.trim()) ? Number(text.trim()) : null);

/** The request body for a schedule, or null while it is incomplete. The server checks the limits. */
export function scheduleBody(draft: ScheduleDraft): ScheduleBody | null {
  if (!parseIsoDate(draft.anchorDate)) return null;
  const anchorDate = draft.anchorDate;
  const interval = wholeNumber(draft.interval);
  switch (draft.recurrence) {
    case "ONCE":
      return { recurrence: "ONCE", anchorDate };
    case "WEEKLY":
      return interval ? { recurrence: "WEEKLY", interval, anchorDate } : null;
    case "MONTHLY":
      // A monthly schedule repeats on its first date's day, or on the last day of each month.
      return interval
        ? { recurrence: "MONTHLY", interval, anchorDate, dayOfMonth: draft.lastDay ? 31 : Number(anchorDate.slice(8, 10)) }
        : null;
    case "TWICE_MONTHLY": {
      const first = wholeNumber(draft.dayOfMonth);
      const second = wholeNumber(draft.secondDay);
      return first && second ? { recurrence: "TWICE_MONTHLY", anchorDate, dayOfMonth: first, secondDay: second } : null;
    }
  }
}

export function patternFromDraft(draft: ScheduleDraft): Pattern | null {
  const body = scheduleBody(draft);
  return body ? toPattern(body) : null;
}

export type AllocationDraft = { accountId: string; mode: AllocationMode; value: string };
export type AllocationBody = { accountId: string; mode: "PERCENT" | "FIXED"; value: string } | { accountId: string; mode: "REMAINDER" };

export function allocationDraftsFrom(allocations: readonly AllocationLike[]): AllocationDraft[] {
  return allocations.map((a) => ({ accountId: a.accountId, mode: a.mode, value: a.value ?? "" }));
}

export function allocationBodies(rows: readonly AllocationDraft[]): AllocationBody[] {
  return rows
    .filter((row) => row.accountId !== "")
    .map((row) =>
      row.mode === "REMAINDER"
        ? { accountId: row.accountId, mode: "REMAINDER" as const }
        : { accountId: row.accountId, mode: row.mode, value: row.value.trim() },
    );
}

/** Allocations for a live preview, or null until every typed value is readable. */
export function allocationsForPreview(rows: readonly AllocationDraft[]): AllocationLike[] | null {
  const allocations: AllocationLike[] = [];
  for (const row of allocationBodies(rows)) {
    if (row.mode === "REMAINDER") {
      allocations.push({ accountId: row.accountId, mode: "REMAINDER", value: null });
      continue;
    }
    const value = parseMoney(row.value, { allowNegative: false });
    if (value === null) return null;
    allocations.push({ accountId: row.accountId, mode: row.mode, value });
  }
  return allocations;
}

export function amountForPreview(text: string): string | null {
  const amount = parseMoney(text, { allowNegative: false });
  return amount === null || amount === "0" ? null : amount;
}
```

```prisma
// its versions. Never deleted by the app; archived instead, so history stays.
model Rule {
  id            String    @id @default(uuid()) @db.Uuid
  householdId   String    @db.Uuid
  name          String
  kind          RuleKind
  category      String?
  notes         String?

  paysAccount Account?             @relation("RulePaysAccount", fields: [paysAccountId], references: [id], onDelete: Restrict)

  overrides   OccurrenceOverride[]

  @@unique([householdId, importRef])
  @@index([householdId])
}

// One period of a rule. The versions of a rule never overlap (an exclusion
// constraint in the migration); "Change from…" ends one and starts the next.
model RuleVersion {
  id            String     @id @default(uuid()) @db.Uuid
  ruleId        String     @db.Uuid
  effectiveFrom DateTime   @db.Date
  // null = open-ended

  recurrence    Recurrence
  interval      Int        @default(1)
  anchorDate    DateTime   @db.Date

  dayOfMonth    Int?
  secondDay     Int?
  note          String?
  createdAt     DateTime   @default(now())

  rule        Rule         @relation(fields: [ruleId], references: [id], onDelete: Cascade)
  allocations Allocation[]

  @@index([ruleId, effectiveFrom])
}

// Where a version's money goes (income) or comes from (a bill: exactly one).

  id            String         @id @default(uuid()) @db.Uuid
  ruleVersionId String         @db.Uuid
  accountId     String         @db.Uuid

  // The order the person entered the splits in.

  ruleVersion RuleVersion @relation(fields: [ruleVersionId], references: [id], onDelete: Cascade)
  account     Account     @relation(fields: [accountId], references: [id], onDelete: Restrict)

  @@unique([ruleVersionId, accountId])
  @@index([accountId])
}

// The person's edit to one occurrence, keyed by the date the rule produced, so it
// survives a new version. Occurrences themselves are computed, never stored.
model OccurrenceOverride {
  id              String           @id @default(uuid()) @db.Uuid
  householdId     String           @db.Uuid
  ruleId          String           @db.Uuid
  scheduledOn     DateTime         @db.Date

  movedTo         DateTime?        @db.Date
  note            String?
  updatedAt       DateTime         @updatedAt
```

```sql
-- ---------------------------------------------------------------------------
-- Rules the database enforces, so a bug elsewhere cannot get past them.

-- Needed for "=" on a uuid inside a GiST exclusion constraint. Trusted, so the
-- owner role that runs migrations may create it.
CREATE EXTENSION IF NOT EXISTS btree_gist;

-- The versions of one rule never overlap. A null end is open-ended.
ALTER TABLE "RuleVersion" ADD CONSTRAINT "RuleVersion_no_overlap"
  EXCLUDE USING gist ("ruleId" WITH =, daterange("effectiveFrom", "effectiveTo", '[]') WITH &&);

ALTER TABLE "RuleVersion" ADD CONSTRAINT "RuleVersion_dates_ordered"
  CHECK (("effectiveTo" IS NULL OR "effectiveTo" >= "effectiveFrom") AND "anchorDate" >= "effectiveFrom");

ALTER TABLE "RuleVersion" ADD CONSTRAINT "RuleVersion_amount_positive" CHECK ("amount" > 0);

ALTER TABLE "RuleVersion" ADD CONSTRAINT "RuleVersion_interval_positive" CHECK ("interval" >= 1);

ALTER TABLE "RuleVersion" ADD CONSTRAINT "RuleVersion_days_in_range"
  CHECK (("dayOfMonth" IS NULL OR "dayOfMonth" BETWEEN 1 AND 31) AND ("secondDay" IS NULL OR "secondDay" BETWEEN 1 AND 31));

-- Two days a month that can never fall on the same date (the second is after
-- the first, and the first is never moved by the month-end rule).
ALTER TABLE "RuleVersion" ADD CONSTRAINT "RuleVersion_twice_monthly_shape"
  CHECK ("recurrence" <> 'TWICE_MONTHLY' OR (
    "interval" = 1 AND "dayOfMonth" IS NOT NULL AND "secondDay" IS NOT NULL
    AND "dayOfMonth" BETWEEN 1 AND 27 AND "secondDay" > "dayOfMonth"));

ALTER TABLE "RuleVersion" ADD CONSTRAINT "RuleVersion_monthly_has_day"
  CHECK ("recurrence" <> 'MONTHLY' OR ("dayOfMonth" IS NOT NULL AND "secondDay" IS NULL));

ALTER TABLE "RuleVersion" ADD CONSTRAINT "RuleVersion_no_days_unless_monthly"
  CHECK ("recurrence" NOT IN ('WEEKLY', 'ONCE') OR ("dayOfMonth" IS NULL AND "secondDay" IS NULL));

ALTER TABLE "Allocation" ADD CONSTRAINT "Allocation_value_fits_mode" CHECK (
  ("mode" = 'PERCENT' AND "value" > 0 AND "value" <= 100)
  OR ("mode" = 'FIXED' AND "value" > 0)
  OR ("mode" = 'REMAINDER' AND "value" IS NULL));

-- At most one REMAINDER per version. An exclusion constraint rather than a
-- partial unique index, because Prisma leaves constraints it doesn't model alone.
ALTER TABLE "Allocation" ADD CONSTRAINT "Allocation_one_remainder"
  EXCLUDE USING btree ("ruleVersionId" WITH =) WHERE ("mode" = 'REMAINDER');

ALTER TABLE "OccurrenceOverride" ADD CONSTRAINT "OccurrenceOverride_confirmed_positive"
  CHECK ("confirmedAmount" IS NULL OR "confirmedAmount" > 0);
```

```ts
import "server-only";
import type { Prisma, PrismaClient } from "@/generated/prisma/client";
import { parseIsoDate, type IsoDate } from "@/lib/calendar-date";
import type { ChangeFromInput, CreateRuleInput, EditVersionInput, StopInput, UpdateRuleInput } from "./input";
import { toStoredVersion, versionInclude } from "./queries";
import type { AllocationLike } from "./splits";
import {
  allocationProblem,
  planChangeFrom,
  planEdit,
  planStop,
  scheduleProblem,
  type RuleErrorCode,
  type RuleKind,
  type VersionDraft,
} from "./versions";

/**
 * Writes for bills and income. Every function takes the household id from the
 * caller's session and filters on it. Each action is one transaction, and the
 * ones that change versions lock the rule's row first, so two edits to one
 * rule run one after the other and each plans from the other's result. The
 * database's own constraints stay the last line of defence.
 */

export class RuleInputError extends Error {
  constructor(readonly code: RuleErrorCode) {
    super(code);
    this.name = "RuleInputError";
  }
}

type Tx = Prisma.TransactionClient;

function throwIf(problem: RuleErrorCode | null): void {
  if (problem) throw new RuleInputError(problem);
}

function dateOf(value: IsoDate): Date {
  const date = parseIsoDate(value);
  if (!date) throw new RangeError(`Not a date: ${value}`);
  return date;
}

const optionalDate = (value: IsoDate | null) => (value === null ? null : dateOf(value));

async function checkAllocations(tx: Tx, householdId: string, kind: RuleKind, amount: string, allocations: AllocationLike[]) {
  const accounts = await tx.account.findMany({
    where: { householdId, id: { in: allocations.map((a) => a.accountId) } },
    select: { id: true, type: true, plaidItemId: true, archivedAt: true },
  });
  if (accounts.length !== allocations.length) throw new RuleInputError("account_not_found");
  if (accounts.some((a) => a.archivedAt !== null)) throw new RuleInputError("account_archived");
  if (accounts.some((a) => a.plaidItemId !== null)) throw new RuleInputError("account_linked");
  const typeOf = new Map(accounts.map((a) => [a.id, a.type]));
  throwIf(allocationProblem(kind, amount, allocations.map((a) => ({ ...a, accountType: typeOf.get(a.accountId) ?? "" }))));
}

async function checkPaysAccount(tx: Tx, householdId: string, kind: RuleKind, paysAccountId: string | null) {
  if (paysAccountId === null) return;
  if (kind !== "BILL") throw new RuleInputError("pays_account_invalid");
  const card = await tx.account.findFirst({
    where: { id: paysAccountId, householdId, type: "credit", archivedAt: null, plaidItemId: null },
    select: { id: true },
  });
  if (!card) throw new RuleInputError("pays_account_invalid");
}

function versionColumns(draft: VersionDraft) {
  return {
    amount: draft.amount,
    recurrence: draft.recurrence,
    interval: draft.interval,
    anchorDate: dateOf(draft.anchorDate),
    dayOfMonth: draft.dayOfMonth,
    secondDay: draft.secondDay,
    note: draft.note,
  };
}

const allocationRows = (allocations: AllocationLike[]) =>
  allocations.map((a, position) => ({ accountId: a.accountId, mode: a.mode, value: a.value, position }));

/** Locks the rule's row for the rest of the transaction, then reads it. */
async function lockRule(tx: Tx, householdId: string, ruleId: string) {
  await tx.$queryRaw`select id from "Rule" where id = ${ruleId}::uuid and "householdId" = ${householdId}::uuid for update`;
  const rule = await tx.rule.findFirst({ where: { id: ruleId, householdId }, include: { versions: versionInclude } });
  if (!rule) throw new RuleInputError("rule_not_found");
  if (rule.archivedAt) throw new RuleInputError("rule_archived");
  return { kind: rule.kind, versions: rule.versions.map(toStoredVersion) };
}

export async function createRule(db: PrismaClient, householdId: string, input: CreateRuleInput) {
  const { version } = input;
  throwIf(scheduleProblem(version, version.effectiveFrom));
  return db.$transaction(async (tx) => {
    await checkAllocations(tx, householdId, input.kind, version.amount, version.allocations);
    await checkPaysAccount(tx, householdId, input.kind, input.paysAccountId);
    return tx.rule.create({
      data: {
        householdId,
        name: input.name,
        kind: input.kind,
        category: input.category,
        notes: input.notes,
        paysAccountId: input.paysAccountId,
        versions: {
          create: {
            effectiveFrom: dateOf(version.effectiveFrom),
            ...versionColumns(version),
            allocations: { create: allocationRows(version.allocations) },
          },
        },
      },
      select: { id: true },
    });
  });
}

export async function updateRule(db: PrismaClient, householdId: string, ruleId: string, input: UpdateRuleInput) {
  await db.$transaction(async (tx) => {
    const rule = await lockRule(tx, householdId, ruleId);
    if (input.paysAccountId !== undefined) await checkPaysAccount(tx, householdId, rule.kind, input.paysAccountId);
    await tx.rule.update({
      where: { id: ruleId },
      data: { name: input.name, category: input.category, notes: input.notes, paysAccountId: input.paysAccountId },
    });
  });
}

export async function changeRuleFrom(db: PrismaClient, householdId: string, ruleId: string, input: ChangeFromInput) {
  return db.$transaction(async (tx) => {
    const rule = await lockRule(tx, householdId, ruleId);
    const plan = planChangeFrom(rule.versions, input);
    if (!plan.ok) throw new RuleInputError(plan.code);
    const { endVersionId, endOn, next } = plan.value;
    await checkAllocations(tx, householdId, rule.kind, next.amount, next.allocations);
    // End the old version first: the new one may not overlap it, even for a moment.
    await tx.ruleVersion.update({ where: { id: endVersionId }, data: { effectiveTo: dateOf(endOn) } });
    const created = await tx.ruleVersion.create({
      data: {
        ruleId,
        effectiveFrom: dateOf(next.effectiveFrom),
        effectiveTo: optionalDate(next.effectiveTo),
        ...versionColumns(next),
        allocations: { create: allocationRows(next.allocations) },
      },
      select: { id: true },
    });
    return { versionId: created.id };
  });
}

export async function stopRule(db: PrismaClient, householdId: string, ruleId: string, input: StopInput) {
  await db.$transaction(async (tx) => {
    const rule = await lockRule(tx, householdId, ruleId);
    const plan = planStop(rule.versions, input.on);
    if (!plan.ok) throw new RuleInputError(plan.code);
    await tx.ruleVersion.update({ where: { id: plan.value.versionId }, data: { effectiveTo: dateOf(plan.value.effectiveTo) } });
  });
}

export async function editRuleVersion(
  db: PrismaClient,
  householdId: string,
  ruleId: string,
  versionId: string,
  input: EditVersionInput,
) {
  await db.$transaction(async (tx) => {
    const rule = await lockRule(tx, householdId, ruleId);
    const plan = planEdit(rule.versions, versionId, input);
    if (!plan.ok) throw new RuleInputError(plan.code);
    await checkAllocations(tx, householdId, rule.kind, input.amount, input.allocations);
    await tx.allocation.deleteMany({ where: { ruleVersionId: versionId } });
    await tx.ruleVersion.update({
      where: { id: versionId },
      data: {
        ...versionColumns(input),
        effectiveTo: optionalDate(plan.value.effectiveTo),
        allocations: { create: allocationRows(input.allocations) },
      },
    });
  });
}

export async function archiveRule(db: PrismaClient, householdId: string, ruleId: string) {
  const rule = await db.rule.findFirst({ where: { id: ruleId, householdId }, select: { id: true } });
  if (!rule) throw new RuleInputError("rule_not_found");
  // Guarded so archiving twice keeps the first date.
  await db.rule.updateMany({ where: { id: rule.id, archivedAt: null }, data: { archivedAt: new Date() } });
}
```

```ts
export async function archiveManualAccount(db: PrismaClient, householdId: string, accountId: string, now: Date = new Date()) {
  const account = await findOwned(db, householdId, accountId);
  if (account.plaidItemId !== null) throw new AccountInputError("not_manual");

  // has no end, or ends today or later. Without a time zone there is no

  const users = await db.rule.findMany({

    select: { name: true },
```

```ts
import { RULE_MESSAGES } from "./messages";

import type { RuleErrorCode } from "./versions";

const STATUS: Record<RuleErrorCode, number> = {
  rule_not_found: 404,
  version_not_found: 404,
  account_not_found: 404,
  rule_archived: 409,
  account_archived: 409,
  rule_ended: 409,
  account_linked: 400,
  income_to_credit: 400,
  bill_needs_one_account: 400,
  needs_one_remainder: 400,
  over_allocated: 400,
  pays_account_invalid: 400,
  anchor_not_on_day: 400,
  anchor_before_start: 400,
  change_not_after_start: 400,
  no_later_occurrence: 400,
  stop_before_version_start: 400,
  end_before_start: 400,
  only_latest_version_can_end: 400,
};

/** Fixed messages only; internal errors are logged by name, never by content. */
export function ruleErrorResponse(error: unknown, route: string): Response {
  if (error instanceof RuleInputError) {
    return jsonNoStore({ error: error.code, message: RULE_MESSAGES[error.code] }, STATUS[error.code]);
  }
  console.error(`[rules] ${route} failed unexpectedly`, { name: error instanceof Error ? error.name : typeof error });
  return jsonNoStore({ error: "internal_error", message: "Something went wrong." }, 500);
}

export const ruleNotFound = () => ruleErrorResponse(new RuleInputError("rule_not_found"), "lookup");
export const versionNotFound = () => ruleErrorResponse(new RuleInputError("version_not_found"), "lookup");
```

```tsx
"use client";

import { useRouter } from "next/navigation";
import { useState } from "react";
import { allocationBodies, emptySchedule, scheduleBody, type AccountChoice, type AllocationDraft } from "@/features/rules/form-drafts";
import type { RuleKind } from "@/features/rules/versions";
import { postJson } from "../post-json";
import { AllocationFields } from "./allocation-fields";
import { ScheduleFields } from "./schedule-fields";

/** Adds a bill or an income stream, with its first version. */
export function RuleForm({ kind, accounts }: { kind: RuleKind; accounts: AccountChoice[] }) {
  const router = useRouter();
  const [schedule, setSchedule] = useState(() => emptySchedule(kind === "INCOME" ? "WEEKLY" : "MONTHLY"));
  const [allocations, setAllocations] = useState<AllocationDraft[]>([{ accountId: "", mode: "REMAINDER", value: "" }]);
  const [error, setError] = useState<string | null>(null);
  const [saving, setSaving] = useState(false);
  const cards = accounts.filter((account) => account.type === "credit");

  async function submit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const data = new FormData(event.currentTarget);
    const body = scheduleBody(schedule);
    if (!body) return setError("Finish the schedule first.");
    setSaving(true);
    const result = await postJson<{ id: string }>("/api/rules", {
      kind,
      name: String(data.get("name") ?? ""),
      category: String(data.get("category") ?? ""),
      amount: String(data.get("amount") ?? ""),
      schedule: body,
      allocations: allocationBodies(allocations),
      ...(kind === "BILL" ? { paysAccountId: String(data.get("paysAccountId") ?? "") || null } : {}),
    });
    setSaving(false);
    if (!result.ok) return setError(result.message);
    router.push(`/bills/${result.data.id}`);
  }

  return (
    <form className="form card" onSubmit={submit}>
      <label>
        Name
        <input name="name" required maxLength={80} />
      </label>
      <label>
        Category <span className="muted">(optional, such as Housing)</span>
        <input name="category" maxLength={40} />
      </label>
      <label>
        Amount
        <input name="amount" inputMode="decimal" required />
      </label>

      <AllocationFields kind={kind} accounts={accounts} value={allocations} onChange={setAllocations} />
      {kind === "BILL" && cards.length > 0 && (
        <label>
          Pays card <span className="muted">(only for a card payment, such as &quot;Amex payment&quot;)</span>
          <select name="paysAccountId" defaultValue="">
            <option value="">None</option>
            {cards.map((card) => (
              <option key={card.id} value={card.id}>
                {card.name}
              </option>

          </select>
        </label>
      )}
      {error && (
        <p role="alert" className="form-error">
          {error}
        </p>
      )}
      <div className="actions">
        <button type="submit" disabled={saving}>
          {kind === "INCOME" ? "Add income" : "Add bill"}
```

```tsx
/** Per-date edits whose date the rule no longer produces: kept and shown, never deleted silently. */
function EditsOffSchedule({ versions, overrides }: { versions: StoredVersion[]; overrides: OverrideView[] }) {
  const orphans = overrides.filter((edit) => ruleOccurrences(versions, edit.scheduledOn, edit.scheduledOn).length === 0);
  if (orphans.length === 0) return null;
  return (
    <section className="notice notice-warn">
      <h2>Edits on dates this no longer produces</h2>
      <p>These were made for dates the schedule no longer has. They are kept, not deleted.</p>
      <ul>
        {orphans.map((edit) => (
          <li key={edit.scheduledOn}>
            {formatIsoDate(edit.scheduledOn)}: {STATUS_LABELS[edit.status]}
            {edit.note ? ` (${edit.note})` : ""}
          </li>
        ))}
      </ul>
    </section>
  );
}
```
